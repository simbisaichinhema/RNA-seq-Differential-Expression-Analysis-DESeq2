# Security Policy

## Supported Versions

Version 1.0.0 is the current release and receives security updates.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly. Please do not open a public issue for security vulnerabilities.

Instead, contact the maintainer at the repository owner's email address or use GitHub's private vulnerability reporting feature if available.

We take all security reports seriously and will work with you to understand and resolve the issue promptly.
