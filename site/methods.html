Methods

Differential Expression with DESeq2

DESeq2 models count data using a negative binomial generalized linear model. The workflow follows these steps:

  1. Count filtering — Remove genes with fewer than 10 counts in fewer than 2 samples, reducing noise from low-expression genes.
  2. Normalization — DESeq2 applies median-of-ratios normalization to account for differences in library size across samples.
  3. Dispersion estimation — Gene-wise dispersion estimates are shrunk toward a fitted trend, stabilizing variance for genes with low counts.
  4. GLM fitting — A negative binomial GLM is fitted for each gene with the design formula ~ Group.
  5. Wald test — Wald tests evaluate the null hypothesis of no difference between groups for each gene.
  6. Multiple testing correction — Benjamini-Hochberg procedure controls the false discovery rate (FDR).
  7. Significance thresholds — Adjusted p-value < 0.05 and |log2FC| > 1.

Visualization

  • PCA — Variance stabilizing transformation (VST) projected onto the first two principal components.
  • Sample Distance Heatmap — Euclidean distances between VST-transformed samples.
  • MA Plot — Log2 fold change vs. mean normalized count per gene.
  • Volcano Plot — −log10(adjusted p-value) vs. log2 fold change, with top genes labeled.
  • Heatmap — Z-score scaled expression of the top 50 most significant DE genes.
  • Enhanced Volcano — Interactive-style volcano with expanded labeling and connector lines.

Functional Enrichment

The top 271 significantly differentially expressed genes (padj < 0.05, |log2FC| > 1) are submitted to clusterProfiler for:

  • GO Biological Process — Hypergeometric test, BH correction, q-value cutoff 0.05
  • GO Molecular Function — Same parameters
  • GO Cellular Component — Same parameters
  • KEGG Pathway — Organism: hsa, p-value cutoff 0.05, BH correction

Pathview is used to render the top enriched KEGG pathway with gene-level expression highlighted.
