Raw Data Files

Metadata

Sample metadata includes: GSM ID, Sample title, Gender, Age, Group (vaccination/infection status), Omicron lineage, Days after PCR, Disease state, Country, and Cell type.

Files are available in data/metadata/Metadata.csv and data/raw/.

Data Provenance

All data originates from the NCBI Gene Expression Omnibus (GEO). Count matrix is sourced from NCBI (GRCh38.p13 reference). Metadata is extracted from the GEO series matrix file. No data was fabricated — all values are from the original public dataset.
