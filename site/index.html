What's in this Repository

📊 DESeq2 Analysis

Complete differential expression analysis from raw GEO counts to significant gene lists, with rigorous statistical testing and multiple testing correction.

🔬 Functional Enrichment

GO enrichment across all three domains (BP, MF, CC) and KEGG pathway enrichment with interactive network and tree plots.

📁 Reproducible

Every script is fully commented with inputs, outputs, and expected runtime. All results are version-controlled and downloadable.

📈 Publication-Quality Figures

31 figures exported in both PNG (300 dpi) and PDF formats, ready for manuscripts and presentations.

📐 Documented

A full scientific report (Introduction through Conclusion), a 6-chapter presentation, and an extensive README make this project accessible to all audiences.

🔗 Ready for CI

GitHub Actions CI pipeline for R script syntax checking and linting ensures long-term code quality.
