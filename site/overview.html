Overview

This project provides a complete, reproducible bioinformatics workflow for comparative RNA-seq analysis of vaccinated and unvaccinated individuals infected with SARS-CoV-2, using data from GEO dataset GSE201530.

The analysis uses DESeq2 for differential gene expression and clusterProfiler with pathview for functional enrichment. All code, data, and results are included.

Project Goals

  • Download and prepare GEO data
  • Perform quality control (PCA, sample distance heatmap)
  • Run DESeq2 differential expression analysis
  • Generate publication-quality figures
  • Characterize enriched GO terms and KEGG pathways
  • Provide a beginner-friendly, fully reproducible workflow

Key Results

  • 445 upregulated genes (padj < 0.05, log2FC > 1)
  • 74 downregulated genes
  • 156 enriched GO Biological Process terms
  • 13 enriched KEGG pathways
  • Dominant enrichment: antiviral innate immune response, interferon signaling
