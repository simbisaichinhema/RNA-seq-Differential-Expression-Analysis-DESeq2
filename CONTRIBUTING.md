# Contributing to RNA-seq-Differential-Expression-Analysis-DESeq2

Thank you for your interest in contributing to this project. This document provides guidelines for contributing.

## How to Contribute

### Reporting Issues

- Use the GitHub issue templates to report bugs or request features.
- Provide a clear description, steps to reproduce, and your environment details.

### Suggesting Improvements

- Open a pull request with a clear description of the change.
- For major changes, open an issue first to discuss the approach.

### Code Contributions

- Follow the Tidyverse coding style used throughout the project.
- Ensure all scripts run without errors.
- Add comments explaining non-obvious code decisions.
- Do not commit generated or intermediate files.

## Development Setup

1. Fork the repository.
2. Clone your fork locally.
3. Create a feature branch.
4. Make your changes.
5. Test your changes.
6. Commit with a clear, descriptive message.
7. Push to your fork and open a pull request.

## Code of Conduct

This project adheres to the [Code of Conduct](CODE_OF_CONDUCT.md). By participating, you are expected to uphold this code.
